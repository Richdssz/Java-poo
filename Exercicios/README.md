## 🗂️ Como Resolver as Questões

1. Abra a pasta do módulo desejado dentro de `Exercicios/` (por exemplo: [`Exercicios/a07OrientacaoAObjetos/`](./a07OrientacaoAObjetos/)).
2. Leia os enunciados detalhados no arquivo `EXERCICIOS.md`.
3. Crie seus arquivos de código Java (ex: `Q01Lampada.java`) na pasta correspondente a cada exercício.
4. Ao concluir, marque com um `[x]` no Tracker correspondente para atualizar seu progresso visual!
