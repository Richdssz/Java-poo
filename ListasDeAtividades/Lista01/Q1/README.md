# Questão 01 — Cadastro de Filmes

Objetivo: implementar uma classe para representar filmes e uma aplicação simples
para instanciar e exibir objetos dessa classe.

Requisitos:

- Crie uma classe `Filme` com os atributos:
	- `titulo` : `String`
	- `genero` : `String`
	- `anoLancamento` : `int`

- Crie um construtor que receba os três valores e inicialize os atributos
	(use `this` nas atribuições).

Aplicação (classe `Main`):

- Na classe `Main` crie exatamente dois objetos da classe `Filme` com os dados abaixo:

	- Filme 1
		- Título: Interestelar
		- Gênero: Ficção Científica
		- Ano de lançamento: 2014

	- Filme 2
		- Título: Toy Story
		- Gênero: Animação
		- Ano de lançamento: 1995

- Exiba no console os dados dos dois filmes usando `System.out.println()`.
	A saída deve identificar cada filme e apresentar título, gênero e ano de lançamento.

Observações:

- Utilize apenas os conceitos trabalhados em sala.
- Não use coleções (vetores, `ArrayList`, etc.) nesta atividade.
- Na classe `Main` crie apenas os objetos solicitados e execute as ações pedidas.
