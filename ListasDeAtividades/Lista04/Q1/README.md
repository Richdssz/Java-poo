# Questão 1 – Sistema de Funcionários

Uma empresa deseja desenvolver um sistema para calcular os salários de seus funcionários. Crie uma classe abstrata Funcionario contendo os atributos nome e salarioBase, além de um método abstrato calcularSalario(). Implemente duas subclasses:

• FuncionarioCLT: o salário final corresponde ao salário-base acrescido de um bônus de 10%.
• FuncionarioPJ: o salário final corresponde ao salário-base, descontando uma taxa administrativa de 5%.

No método main, crie objetos dos dois tipos e exiba os salários calculados.
