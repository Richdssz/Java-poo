# Questão 8 – Cadastro de Produtos

Crie uma classe Produto com os atributos nome, preco e quantidade. No construtor, valide os seguintes requisitos:

• O nome não pode ser vazio.
• O preço deve ser maior que zero.
• A quantidade não pode ser negativa.

Caso alguma regra seja violada, lance uma IllegalArgumentException com uma mensagem adequada. No método main, utilize try-catch para realizar o cadastro de diferentes produtos, incluindo alguns com valores inválidos.
