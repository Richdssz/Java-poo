# Questão 9 – Exceções Personalizadas

Desenvolva um sistema de biblioteca que controle a quantidade de exemplares disponíveis de um livro. Crie uma classe Livro com os atributos titulo e exemplaresDisponiveis.

Implemente o método emprestar(), que reduz a quantidade de exemplares disponíveis em uma unidade. Quando não existirem exemplares disponíveis, o método deverá lançar uma exceção personalizada chamada LivroIndisponivelException.

No método main, crie um livro com dois exemplares e tente realizar três empréstimos, tratando adequadamente a exceção.
