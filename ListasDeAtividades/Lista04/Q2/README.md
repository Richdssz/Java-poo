# Questão 2 – Sistema de Formas Geométricas

Uma aplicação precisa calcular a área de diferentes figuras geométricas. Crie uma classe abstrata FormaGeometrica que possua o método abstrato calcularArea(). Implemente as subclasses Circulo, Retangulo e Triangulo, cada uma com os atributos necessários para calcular sua área.

No método main, armazene diferentes formas em um vetor do tipo FormaGeometrica e percorra-o, exibindo a área de cada objeto.
