# Questão 4 – Sistema de Pagamentos

Uma loja virtual deseja permitir diferentes formas de pagamento. Crie uma interface Pagamento contendo o método:

void processarPagamento(double valor);

Implemente as classes PagamentoPix, PagamentoCartao e PagamentoBoleto. Cada classe deve apresentar uma mensagem diferente ao processar o pagamento, informando o valor e a modalidade utilizada.

No método main, crie um vetor do tipo Pagamento com objetos das três classes e execute o método para cada um deles.
