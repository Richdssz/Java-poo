# Questão 7 – Divisão Segura

Desenvolva um programa que solicite dois números inteiros ao usuário e realize a divisão do primeiro pelo segundo. O programa deverá utilizar try, catch e finally para:

• Tratar a tentativa de divisão por zero.
• Tratar entradas que não sejam números inteiros.
• Exibir, no bloco finally, uma mensagem informando que a operação foi encerrada.
