# Programação Orientada a Objetos em Java

Repositório dedicado ao estudo e prática dos conceitos fundamentais e avançados de Programação Orientada a Objetos (POO) em Java, incluindo materiais teóricos em PDF e códigos de exemplo práticos.

---

## 👨‍🏫 Créditos e Referências

Este repositório acompanha as aulas de POO ministradas pelo **Professor Daniel** ([@danibez](https://github.com/danibez)).

Os materiais teóricos e slides presentes na pasta [`Pdfs/`](Pdfs) foram disponibilizados a partir do conteúdo didático elaborado pelo **Professor Márcio Bueno**, referência no ensino da disciplina:

- 🌐 **Site do Prof. Márcio Bueno:** [Programação Orientada a Objetos](https://marciobueno.com/ensino/programacao-orientada-objetos/)

---

## 📌 Estrutura do Repositório

O repositório está organizado em duas partes principais:

- **`Assuntos/`**: Código-fonte em Java contendo os projetos práticos divididos por módulos em `camelCase`.
- **`Exercicios/`**: Cadernos de exercícios e desafios autorais desenvolvidos por Richd ([Richdssz](https://github.com/Richdssz)) por iniciativa própria para fortalecer e consolidar a base prática em Java (UNICAP).
- **`Pdfs/`**: Slides e apostilas teóricas em PDF correspondentes aos módulos do curso.

## 🛠️ Como Executar

### Pré-requisitos

- Java Development Kit (JDK 17 ou superior)
- IDE (IntelliJ IDEA, VS Code ou Eclipse)

### Execução via Terminal

Para compilar e rodar qualquer classe a partir da raiz do repositório:

```bash
# Compilando os arquivos do módulo de Associações
javac Assuntos/a08Associacoes/cadastroClientes/*.java

# Executando a classe principal
java Assuntos.a08Associacoes.cadastroClientes.Rodar
```
